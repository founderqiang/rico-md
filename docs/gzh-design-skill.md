# gzh-design-skill 主题

在编辑器的「主题 → gzh-design-skill」选择以下主题；支持收藏、保存主题选择、字号缩放及复制到公众号。

| 主题 | 排版特点 |
| --- | --- |
| 摸鱼绿 | 绿色杂志标题、浅绿引用卡、黄色高亮，14px 正文 |
| 红白色系 | 红色章节线、白底开篇引言卡、红色表头，15px 正文 |
| 石墨极简风 | 灰阶、细线、宽松章节间距，15px 正文 |

| 摸鱼票据风 | 米黄纸底、黑框硬阴影、绿色撕票虚线，14px 正文 |
| 橄榄手记 | 米白底、墨黑刊头、橄榄灰边框与橙色划线，14px 正文 |
| 墨蓝刊读风 | 黑白刊读封面、克莱因蓝点缀与衬线章节编号，14px 正文 |

这是面向通用 Markdown 的主题适配，覆盖标题、段落、强调、引用、列表、代码、表格、分隔线和图片。红白、石墨主题将文章开头（或一级标题之后）的引用显示为引言卡。`<u>关键词</u>` 使用各主题的下划线色，`<mark>关键词</mark>` 使用主题高亮色；标准 `**加粗**` 保留文字加粗，不把下划线挂在 strong 上。

## 封面标题写法

摸鱼绿、摸鱼票据、橄榄手记、墨蓝刊读风的一级标题都支持 `|`（也支持全角 `｜`）分隔的封面元数据。原有简写 `# 主标题 | 顶部标签 | 底部署名 | 日期 | 作者` 仍可使用；需要控制主题的刊头或装饰位时，使用具名字段：

```md
# 主标题 | label=刊头 | subtitle=摘要 | issue=NO. 001 | footer=底部左文案 | footerRight=底部右文案 | author=甲木
```

`label` 是顶部刊头，`subtitle` 是标题下摘要，`summary` 是摸鱼票据风留白区域中的简短导语，`issue` 是期号/票号，`footer` 与 `footerRight` 分别控制底部左右文字，`author` 可作为右侧署名。摸鱼票据风的默认票号为 `NO. 001`，会以标签与三位编号两级排版；也可直接写任意期号。它在只填写基础字段时会自动收紧封面；填写 `aside=深度观察` 或 `grade=S` 后会保留参考图那种更高的票据比例。它还支持 `tags=SKILLS,AGENT`；橄榄手记的插画下方文字也使用 `aside`。未填写的字段不会生成原先不可编辑的默认文案。

不必手写字段：选中支持封面的主题后，可在该主题分组底部点击“插入模板”。编辑器会保留首行主标题，仅替换这一行已有的封面字段；不支持封面字段的主题会将按钮置灰。

摸鱼票据风会插入接近参考图的完整示例。`stars=5` 显示刊头右侧的五颗星，支持 1–5；`author` 显示摘要上方的作者名，`authorBio` 显示作者下方的简介。`summary` 显示浅绿摘要框，`tags` 显示框下标签，`aside` 和 `grade` 控制右侧票根，`footer` / `footerRight` 控制底部左右文案。所有字段均可修改或删除，缺省区域自动收起，不保留固定高度的空白。

橄榄手记选中后，主题面板会提供“上传图片”。上传的本地图片会自动作为右侧封面图写入 `coverImage=img://…`；未上传时不会显示固定插画。

摸鱼绿有至少两个 `##` 章节时，会在封面下方自动生成横向可滑动的目录。章节标题可写成 `## 能力商品 | Skill 的定义`，左侧为目录标题，`|` 后内容作为卡片要点。

原项目是由 Agent 按文章内容组合组件的排版技能。此适配不自动改写文章，不凭空添加评分、作者、目录摘要或封面插画，也不将其长图直接作为可编辑主题。原稿手工组合的工具卡、时间线等专用组件不由普通 Markdown 自动生成。编辑器仍允许用户调整字号。

为了手机阅读，小号绿色文字使用较深的绿色；长链接可换行，表格沿用编辑器横向滚动与公众号导出处理。切换主题不依赖外部字体或开发目录。
